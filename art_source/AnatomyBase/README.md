# Generic anatomy source

Bundle downloaded from Blender's official distribution:

https://download.blender.org/demo/asset-bundles/human-base-meshes/human-base-meshes-bundle-v1.2.0.zip

The source archive and extracted editable `.blend` are preserved here. Blender's Human Base Meshes are distributed as CC0 assets. The imported realistic hand identifies **Dan Ulrich**, license **CC0**, and describes realistic scan data in its Blender asset metadata; that metadata was inspected through the Blender MCP connection. Head topology comes from the bundle's `GEO-head_animation_realistic` object.

The thumbnails were actually inspected before use. These are generic anatomical working assets, not visual evidence of Matt Trakker's official real-world appearance. The user explicitly authorized a realistic human interpretation of the supplied illustrated portrait on 2026-11-02, without likeness to a particular real person.

Matt V4 retains the existing Matt armature, head object and weighted suit. The anatomical topology was adapted to that character; it is not a second character used for a separate pose or masked state. Temporary source objects were removed from the assembled scene after transfer. Hands are continuous glove meshes. Previous glove sources are kept in a hidden editable source collection, not displayed as alternative characters.

Provenance: `../Matt_Trakker/anatomy_provenance_v4.json`. Initial inventories and inspected asset metadata: `../../docs/qa/anatomy_objects.json` and `anatomy_rear_measurements.json`.
